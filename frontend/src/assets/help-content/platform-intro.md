## 平台介绍

shwsq'aiagent 平台是一个基于 FastAPI + Vue 3 的 AI 智能体平台，支持工作流编排、代码工具、知识库检索、智能体对话等功能。

### 功能特性

- **对话界面**：用户与智能体的实时对话界面，支持文本输入和输出，以及文件上传下载等功能，有通用模式，智能体调用模式和测试智能体模式
  - **通用模式**：用户直接与大模型对话，支持文本图片和文件输入，以及文本图片输出
  - **智能体调用模式**：用户通过`@智能体名称`调用智能体，或直接输入智能体调用指令，后端会自动识别是否需要调用智能体，并识别智能体参数
  - **测试智能体模式**：用户通过`@智能体名称`和选择测试用例文件夹测试智能体功能
- **智能体管理**：支持 API 智能体和工作流智能体两种类型
- **工作流引擎**：纯代码编排工作流，支持节点和代码混合编程
- **代码工具**：可复用的 Python 函数工具，支持数据处理、图表生成、文件导出等
  - 可以在工作流中调用，调用方法为`await ctx.call_tool("工具名称", 参数)`
  - 详见 [代码工具](code-tool.md)
- **知识库系统**：支持 RAG 检索增强生成，多知识库管理
- **API 配置**：多模型 API 配置管理

### 智能体类型

- **API 智能体**：基于 API 的传统智能体，直接调用大模型
- **工作流智能体**：基于纯代码编排的智能体，通过工作流语言定义流程逻辑，支持节点和代码混合编程
  - **节点**：工作流中的基本单元，执行具体的任务或操作
  - **代码**：节点中包含的 Python 代码，用于实现节点的功能
  - 详见 [工作流语言](workflow-language.md)
